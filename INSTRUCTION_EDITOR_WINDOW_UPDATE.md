### 3. ✅ Вибір мови AI моделі

**Зміни в моделі `UserInstruction.cs`:**
```csharp
public string? AiLanguage { get; set; } = null;
```
- Додано поле для збереження вибраної мови AI
- `null` означає автоматичне визначення з мови інтерфейсу

**Зміни в UI:**
- Додано `ComboBox` з опціями:
  - **Auto** (визначається з мови UI)
  - **English** (en)
  - **Українська** (uk)
  - **Русский** (ru)
  - **Deutsch** (de)
  - **Türkçe** (tr)

**Логіка роботи:**
- При завантаженні: зчитує збережену мову з бази даних
- При збереженні: зберігає вибір користувача
- `Tag` кожного елемента ComboBox містить код мови або порожній рядок для Auto

## Технічні деталі

### Архітектура
- **База даних**: LiteDB автоматично обробляє нове поле `AiLanguage`
- **Сервіси**: `UserInstructionService` не потребує змін
- **Локалізація**: Використання `DynamicResource` для автоматичного оновлення при зміні мови

### Сумісність
- Старі записи в БД будуть мати `AiLanguage = null` (Auto режим)
- Нові записи зберігатимуть вибір користувача

### UI/UX покращення
- Консистентний дизайн з іншими вікнами
- Підтримка drag-and-drop для переміщення вікна
- Кнопки мінімізації та закриття
- Темний дизайн з контрастними акцентами

## Використання

### Для користувачів:
1. Відкрийте редактор інструкцій
2. Введіть вашу інструкцію для AI
3. Налаштуйте розмір контексту (2048-8192)
4. Налаштуйте максимум токенів (256-2048)
5. **Виберіть мову AI моделі** або залиште Auto
6. Натисніть "Зберегти"

### Для розробників:
```csharp
var instruction = _instructionService.GetUserInstruction();
string aiLang = instruction?.AiLanguage ?? ""; // "" = Auto
```
