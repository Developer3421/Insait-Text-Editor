I recently finished 5 apps and published them on the Microsoft Store. These are complex, interesting projects that reflect my progress as a creator and software developer. This post is about my **Insait Text Editor**.

Insait is a modern Windows text editor built with **.NET 10** and **Avalonia UI**, designed for writing, notes, and drafting—while keeping everything **private**.

## What makes it special
- **Local AI assistant (offline)** — no accounts, no cloud, no data leaving your PC.
- Powered by a **local Gemma 3 (1B) model** running directly on your device via **LLamaSharp / llama.cpp**.
- **Streaming responses** in chat (you see the answer appear in real time).
- **Context-aware conversations** + **long‑term memory** (saved locally).

## Editor features I’m proud of
- Multi‑tab workflow
- Rich formatting shortcuts (**bold / italic / underline**)
- Smart word wrap
- Ruled backgrounds: **lined / grid / plain**
- Custom styling: font size, colors, line spacing
- Auto‑save + session restore

## Why I built it
I wanted an editor where the AI feels like a helpful coworker—but still respects privacy. Running **Gemma 3 locally** made that possible: fast answers, offline work, and full control over my data.
